Naive Bayes Classifier — Interactive Step-by-Step Visualizer

Using Bayes' Theorem combined with the Naive Independence Assumption: P(Class | X) ∝ P(Class) × ∏ P(xⱼ | Class). For continuous data, it estimates class priors P(Class), feature means (μ), and variances (σ²) to form Gaussian likelihood distributions. Classification is performed via probabilistic scoring without iterative gradient descent.

Algorithm: Naive Bayes (Gaussian) Optimization: Closed-form MLE (Counting & Statistics) Loss Metric: Negative Log-Likelihood Project Context: Telecom Churn Prediction (High Recall)
